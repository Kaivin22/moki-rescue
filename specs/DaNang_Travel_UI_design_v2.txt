AESTHETIC REFERENCE — /apply-aesthetic

Aesthetic personality: "Nature-Warm Playful"
  Tone        : Warm, inviting, trustworthy — như một người bạn địa phương
                dẫn đường, không lạnh lùng corporate.
  Energy      : Playful nhưng không childish. Soft nhưng không nhạt.
  Inspiration : Ứng dụng tham chiếu có cards nổi nhẹ trên nền xanh sage,
                accent vàng amber nổi bật cho CTA, olive green cho secondary.
                Cards "float" với soft shadow, không sharp edge.
                Rounded pill shapes cho buttons và tags.
                Large bold numbers và headings tạo visual hierarchy rõ ràng.

Visual fingerprint:
  - Cards: border-radius 20px, box-shadow rgba(45,51,32,0.08) 0 4px 16px
  - Buttons: full-width pill r=26, 52px height
  - Background: #F7F7F5 main, #B5C6B1 tinted sections
  - Accent: #DDA92E amber — tất cả primary CTA, active states, highlights
  - Secondary: #A8B468 olive — secondary actions, tags, icons
  - Text dark: #2D3320 (near-black từ olive family)
  - Illustrations: flat 2D, travel-themed (compass, map, luggage, landmark)

Closest reference systems: Airbnb (warmth + trust) × Duolingo (playful cards)
Apply this aesthetic to all generated code. Override any system defaults that
conflict with this personality.

WCAG 2.2 AA REQUIREMENTS (apply to ALL screens)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Color contrast minimums:
  Dark text #2D3320 on #F7F7F5 → ratio 9.2:1 ✅ AAA
  Dark text #2D3320 on #DDA92E → ratio 6.8:1 ✅ AA
  White #FFFFFF on #A8B468    → ratio 3.2:1 ⚠ FAIL for normal text
    → Fix: use #2D3320 on olive instead of white, or use #6B7240 (olive.600)
  White #FFFFFF on #2D3320    → ratio 16:1 ✅ AAA
  Sage #7A8A6E on #F7F7F5     → ratio 4.8:1 ✅ AA (secondary text OK)

Touch targets: minimum 48×48px for ALL tappable elements (WCAG 2.5.5)
  → AppButton height 52px ✅
  → Star rating tappable area 48px ✅
  → Heart save icon: minimum 48px InkWell target ✅
  → Swipe-to-delete: additional keyboard/long-press alternative required

Focus indicators: visible outline on all interactive elements (WCAG 2.4.7)
  → focused border: olive.400 2px (input fields) ✅
  → Flutter FocusNode + custom focusColor on all buttons

Screen reader (WCAG 1.1.1):
  → CachedNetworkImage always has semanticLabel
  → CategoryIcon emojis wrapped in Semantics excludeSemantics:false, label: category name
  → Decorative images: Semantics excludeSemantics:true
  → Rating: Semantics label "Đánh giá 4.5 trên 5, 120 lượt đánh giá"
  → Charts: semantic description in tooltip and accessible label

Never rely on color alone (WCAG 1.4.1):
  → StatusBadge: always text + color (not just dot)
  → Selected state: checkmark icon + color change
  → Error state: error icon + red border + error text

Animation: respect system prefers-reduced-motion (WCAG 2.3.3)
  → Wrap AnimatedContainer, AnimatedOpacity với:
    if (MediaQuery.of(context).disableAnimations) { /* instant */ }
